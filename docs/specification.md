# 模拟研究与核查规范

## 数据与分析约定

- 120名模拟受试者，Active与Placebo各60人；所有人假定接受给药。
- 固定随机种子20261008；每人0–3条不良事件，再加入两条异常记录。
- 日期为完整ISO日期；本示例不处理部分日期或缺失日期。
- 汇总按唯一受试者计数，重复AE不重复计算人数，分母为各组全部受试者。
- 孤立AE及结束早于开始的记录保留在原始数据和核查清单中，但不进入演示汇总。
- 年龄异常提出质疑，仍保留在假定已给药的安全性总体中。
- 核查清单不代表真实EDC中已发送或关闭的Query。

## Edit checks / UAT

|规则|条件|动作|阳性用例|阴性用例|
|---|---|---|---|---|
|DM001|年龄小于18或大于75|提示资格范围异常|DEMO-001，16岁|18岁及75岁|
|AE001|AE受试者不存在于DM|提示关联失败|UNKNOWN|正常关联AE|
|AE002|结束早于开始日期|提示日期矛盾|DEMO-001，AESEQ=99|正常日期AE|

六项测试验证预设异常定位、按人数统计、可复现性、异常排除、空总体和年龄边界。
